Chāyā OCR app

Bookchop

Mark and label regions of a PDF, optionally with AI assistance, and save the PDF and regions together.

Applications

  • Mark and read

    Draw, move, resize, and label regions, then switch to Read to view the selected snippets.

  • Marking workspace

    A simplified interface focused on marking regions, with the same PDF package format.

Both applications save .chaya ZIP packages containing the PDF and annotations. These differ from the JSON files saved by the original Chāyā OCR app.

Early prototypes

Open the latest annotator, select a PDF, draw and label regions, then export the annotations as JSON. Open the snippet viewer with the same PDF and the exported JSON.

  • Latest annotator: fit to width

    Fits pages to the available width and exports regions in PDF coordinates.

    retry-v2-pdfcoord-v3.html

  • Snippet viewer

    Displays labeled snippets from a PDF and annotations saved in PDF coordinates.

    retry-reader.html

Earlier annotators
