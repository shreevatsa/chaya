Bookchop

Mark and label regions manually or with AI assistance. Both interfaces save interchangeable .chaya ZIP packages containing the PDF and annotations. These differ from the OCR editor's JSON files.

  • Mark and read

    Draw, move, resize, and label regions, then switch to Read to view the selected snippets.

  • Marking workspace

    A simplified interface focused on marking regions.

Early Bookchop prototypes

To try the original workflow, use the fit-to-width annotator to label PDF regions and export JSON. Open the snippet viewer with the same PDF and that JSON.

  • Annotator: fit to width

    Fits pages to the available width and exports regions in PDF coordinates.

  • Snippet viewer

    Displays labeled snippets from a PDF and annotations saved in PDF coordinates.
